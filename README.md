# Сложно сосредоточиться

Проектная работа курса «Веб-разработчик» от Яндекс Практикум.

## Описание

Адаптивный лендинг о проблемах концентрации внимания.  
Сайт поддерживает светлую и тёмную цветовые схемы с автоматическим  
переключением в зависимости от системных настроек пользователя.

## Технологии

- Mobile First подход
- Адаптивная вёрстка: 375px, 768px, 1024px

## Функциональность

- Тёмная и светлая тема оформления
- Автоматическое определение системной темы (prefers-color-scheme)
- Принудительное переключение темы кнопками
